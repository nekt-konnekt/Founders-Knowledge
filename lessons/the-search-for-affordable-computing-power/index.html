The cheapest server is only a bargain if it can reliably handle the work your clients depend on.

“

Our journey began with a practical challenge. We wanted to run Hermes Agent and Claude Code to support a service we provide to clients. The plan was to have six AI agents running concurrently, but our current computer couldn’t comfortably handle that workload.

01 — THE CHALLENGE

Could cloud infrastructure give us room to grow?

Rather than immediately investing in a more powerful machine, we started exploring cloud infrastructure. Could we rent the computing power we needed at a reasonable monthly cost and build a setup that could grow alongside the business?

Our budget was between $10 and $20 per month. That meant we had to look beyond attractive prices and consider what each provider actually offered: computing resources, reliability, flexibility and the ability to keep our clients’ agents available.

Three options caught our attention: Hetzner, Agent37 and Contabo.

02 — THREE PROVIDERS, THREE APPROACHES

What each option brings to the table.

Hetzner: Computing power with greater control

Hetzner stood out as a conventional cloud infrastructure option. A VPS gives us a remote machine on which we can install and configure the software we want, rather than being restricted to a specialised agent-hosting environment.

The appeal is control. We can shape the environment around our workflow, install the tools we need and manage the processes that keep our agents running.

In our comparison, we noted a configuration advertised at about $7.49 per month for 2 vCPUs and 4 GB of RAM. That figure and configuration must be checked against the exact server, region and current checkout price before a purchase; pricing can vary by plan and billing details.

The trade-off is that we take on more responsibility for setup, security, monitoring and maintenance. We also need to verify the exact server specifications and price available at checkout.

Agent37: Convenience for AI agents

Agent37 caught our attention because it offers hosting options specifically aimed at running AI agents, including Hermes Agent.

Its managed Hermes hosting has been advertised from $3.99 per month for a Basic plan. A separate Cloud API option we examined showed a 2-vCPU, 4-GB RAM instance with 4 GB of disk space at about $4.76 per month if running continuously, or around $0.0065 per hour while running. That Cloud API option can sleep when idle; the disk charge continues while it sleeps, estimated in our comparison at roughly $0.36 per month.

These are different products, not interchangeable plans. The managed hosting option is presented as always-on, while the Cloud API instance is designed to sleep when idle. Before choosing either, we would need to confirm the exact uptime behaviour, the supported concurrency, and whether our intended Claude Code workflow is supported.

The appeal is convenience. A purpose-built environment could reduce the amount of manual setup involved in getting an agent running. But a low entry price is attractive only if the service fits the workload and keeps client-facing agents available when required.

Contabo: More resources for the money

Contabo emerged as an interesting candidate because of the specifications advertised on its VPS plans and its one-click Hermes installation option.

Its Cloud VPS 4 plan lists 4 vCPUs and 8 GB of RAM, while the Cloud VPS 6 lists 6 vCPUs and 12 GB of RAM. During our research, the displayed prices were approximately $6.60 and $9.00 per month respectively, with lower promotional rates advertised for longer commitments: about $5.28 and $7.20 per month under the offer shown.

Those specifications make Contabo worth investigating for a workload involving multiple agent processes. Still, advertised resources are only one part of the decision. We must also consider the actual checkout price, billing commitment, performance under load and the work involved in maintaining the server. Initial setup may be assisted, but maintenance and troubleshooting for additional software remain our responsibility.

There is a crucial distinction: having enough memory to run agent software does not mean the server can run large AI models locally. If our agents use cloud-based models, model inference happens with the external provider, while the VPS runs the agents, tools, integrations and background processes.

!
Pricing is a moving target

The prices above reflect figures captured during our research, not a guarantee of current availability or final checkout cost. Promotional pricing, subscription length, taxes, server location and usage can change the total. Confirm the final price and terms directly with each provider.

03 — CAPACITY, NOT JUST PRICE

Six agents change the calculation.

Six agents running concurrently introduce a different set of considerations from running a single assistant.

Each agent may be waiting for instructions, calling an API, executing tools, handling files or performing background tasks. Their resource consumption will vary depending on what they are doing. Six mostly idle agents are not the same workload as six agents actively running complex jobs.

We also have to think beyond computing power. A client-facing service needs dependable uptime, secure handling of client credentials, sensible separation of client data and a way to recover when a process fails.

That is why the cheapest plan is not automatically the best choice. A server that struggles under load or requires frequent intervention can cost us more in lost time and disrupted service than we save on hosting.

We also need to account for costs outside the VPS itself, including AI model usage, backups and any additional services. Renting a server provides computing capacity; it does not make the AI models or every supporting service free. API rate limits and model-provider charges remain separate considerations.

04 — WHAT MAKES SENSE FOR OUR BUDGET?

Start with a test, not an assumption.

With $10–$20 per month available for infrastructure, Contabo’s advertised 4-vCPU/8-GB plan looks like a reasonable candidate for an initial test. The 6-vCPU/12-GB option offers more headroom, provided its final price and billing terms fit our budget.

Hetzner remains worth comparing for its flexibility, while Agent37 may be attractive if its hosting environment supports our complete workflow and continuous-availability requirements.

These are candidates, not yet proven winners. The sensible next step is to deploy the actual agent setup, run all six agents together, measure memory and CPU usage, test recovery after failures and confirm that each client’s agents remain accessible. We should make a final choice based on those results rather than specifications alone.

BEFORE COMMITTING TO A PLAN

  • Can all six agents run concurrently without exhausting memory or CPU?
  • Do the agents stay available, or can the service sleep or time out?
  • Can each client’s data, files and credentials be kept separate?
  • What are the real monthly costs after model usage, backups and add-ons?
  • How easily can we restart a failed process and inspect logs?

05 — THE BIGGER LESSON

Infrastructure is part of the business model.

For founders building AI-powered services, infrastructure decisions are part of the business model. The objective is not to buy the biggest server available or chase the lowest advertised price. It is to find a dependable starting point that supports the current workload while leaving room to grow.

Our search for a place to run six AI agents has become a lesson in evaluating cloud infrastructure with a founder’s mindset: understand the workload, test the assumptions, calculate the full cost and pay for capacity that serves a clear business purpose.

THE TAKEAWAY

The goal is not simply to get six agents running. It is to build a service that can support its clients reliably, within a budget the business can sustain.
